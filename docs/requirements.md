# 要件定義書：人工知能学会全国大会 発表情報クローラー

## 1. プロジェクト概要

人工知能学会全国大会（JSAI）の発表情報を自動収集し、傾向分析に利用可能なCSV形式で出力するクローラーを構築する。

---

## 2. 対象データ

### 2.1 収集範囲

| 項目 | 内容 |
|------|------|
| 対象サイト | https://confit.atlas.jp/guide/organizer/jsai/events |
| 対象年度 | 2018年度（第32回）〜 最新年度（2025年度）|
| 対象セッション種別 | 口頭発表・ポスター発表・招待講演など全セッション |

### 2.2 収集項目（CSV出力カラム）

| カラム名 | 説明 | 備考 |
|----------|------|------|
| 大会年度 | 例：`2024` | |
| セッションID | 例：`1E1` | タイムテーブル上のセッション識別子 |
| 発表ID | 例：`1E1-01` | 発表番号（`[1E1-01]` 形式から抽出） |
| 発表タイトル | 発表のメインタイトル | |
| 発表サブタイトル | サブタイトル（存在しない場合は空文字）| |
| キーワード | コンマ区切りのキーワード群 | |
| 要約 | アブストラクト本文 | |

## 3. 機能要件

### FR-01: 大会一覧の収集

- https://confit.atlas.jp/guide/organizer/jsai/events から2018年度以降の大会トップページURLを収集する
- 例：`https://confit.atlas.jp/guide/event/jsai2024/top`

### FR-02: 日程一覧の収集

- 各大会のトップページから全日程（口頭・ポスター）のタイムテーブルURLを収集する
- 2024年度以降では `_poster` サフィックスを持つポスター日程ページも含める

### FR-03: セッション情報の収集

- 各日程タイムテーブルページから全セッションへのリンクを収集する
- セッションURLはトークンパラメータを含む場合がある（例：`?shkTXsFRBo`）
- 年度ごとにトークン値が異なる

### FR-04: 発表情報の収集

- 各セッションページから全発表へのリンクを収集する
- 各発表ページから以下の情報を抽出する
  - 発表ID（`[1E1-01]` 形式）
  - タイトル
  - サブタイトル（存在する場合）
  - キーワード
  - 要約（アブストラクト）

### FR-05: CSV出力

- 収集したデータをUTF-8 BOM付きCSV形式で出力する
- ファイル名：`jsai_presentations_{YYYYMMDD_HHMMSS}.csv`
- ヘッダー行あり

### FR-06: 進捗管理・再開機能

- クローリング中断後に途中から再開できること
- 収集済みURLをJSONファイルに記録し、再実行時にスキップする

### FR-07: エラーハンドリング

- ページ読み込み失敗時はリトライ（最大3回）
- リトライ後も失敗した場合はエラーをログに記録してスキップ
- エラーリストを別ファイルで保存

---

## 4. 非機能要件

### NFR-01: クロール負荷抑制

- ページリクエスト間に1〜3秒のランダム待機を設ける
- 連続エラー時は待機時間を指数バックオフで延長する
- 同一ホストへの同時接続数は1本に制限する

### NFR-02: JavaScript対応

- 対象サイトはJavaScript（SPA）で動作するため、Playwright（ヘッドレスブラウザ）を使用して動的レンダリング後のDOMを解析する

### NFR-03: 処理速度

- 全年度（2018〜2025年度）の完全クロールを24時間以内に完了させること（目安）
- 年度単位で並列処理を行わず、順番に処理することでサーバー負荷を抑制する

### NFR-04: ログ出力

- ログはファイルおよびコンソールに出力する
- ログレベル：INFO（進捗）、WARNING（スキップ）、ERROR（失敗）

### NFR-05: 実行環境

- Python 3.10以上
- macOS / Linux 対応
- 仮想環境（venv）を使用して依存関係を管理する

---

## 5. 制約・前提条件

| 項目 | 内容 |
|------|------|
| データ利用目的 | 研究・分析目的の個人利用 |
| 著作権 | 収集データの著作権は人工知能学会に帰属するため、公開・再配布は行わないこと |
| AWS WAF対策 | AWS WAF統合が実装されており、自動化検出時はCAPTCHAが発生する可能性がある |
| ログイン | ログインなしでアクセス可能な情報のみを対象とする |
| PDFダウンロード | 発表論文PDFの収集は対象外 |

```
output/

```

## 7. URL構造（参考）

| ページ | URL パターン | 例 |
|--------|-------------|-----|
| 大会一覧 | `/guide/organizer/jsai/events` | — |
| 大会トップ | `/guide/event/jsai{YYYY}/top` | `jsai2024/top` |
| 日程（口頭） | `/guide/event/jsai{YYYY}/table/{YYYYMMDD}` | `table/20240528` |
| 日程（ポスター） | `/guide/event/jsai{YYYY}/table/{YYYYMMDD}_poster` | `table/20240528_poster` |
| セッション | `/guide/event/jsai{YYYY}/session/{id}/tables?{token}` | `session/1E01-05/tables?shkTXsFRBo` |
| 発表 | `/guide/event/jsai{YYYY}/subject/{id}/tables?cryptoId=` | `subject/1E1-01/tables?cryptoId=` |
